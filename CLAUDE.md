## Architecture

Single-page React + Vite site (no TypeScript, no test suite). All source is in two files:

- [src/main.jsx](src/main.jsx) — the entire `App` component plus all data constants (nav items, Instagram post shortcodes, TikTok video IDs, menu items, story photos)
- [src/FrameGallery.jsx](src/FrameGallery.jsx) — SVG photo-frame component
- [src/styles.css](src/styles.css) — all styles, mobile-first with `clamp()` fluid sizing and three breakpoints (860px, 700px, 560px, 680px, 380px)

### FrameGallery two-phase render

`FrameSVG` (memoised) renders SVG frames with photos clipped to SVG shapes:

1. **Phase 1** (`useEffect`) — fetches the SVG file, marks every element with `fill="#FF0000"` via `data-fg-index`, serialises back to HTML string, sets as `dangerouslySetInnerHTML`
2. **Phase 2** (`useLayoutEffect`) — after DOM update, walks the real SVG DOM: for each marked element creates a `<clipPath>` (using a clone of that element) plus an `<image>` that sources from the `photos` prop array, cycling with `i % photos.length`

The memo boundary is intentional: lightbox open/close in the parent must not trigger a re-render of `FrameSVG` because `dangerouslySetInnerHTML` would wipe the phase-2 DOM work.

### Flame curve generation

`public/flame-curves/curve-00{1..5}.json` are generated by `scripts/gen-curves.js` from two raw masters in `scripts/raw/`. The generator applies:
- X-monotonicity enforcement on the middle 50% of bezier nodes (no backward sweep)
- Self-intersection detection (aborts on failure)
- A sine-arch mid-boost to raise the flame's middle section
- Peak-shift transforms (`shiftPeak`) to move the spike tip within a node group

Edit `scripts/raw/curve-001.json` or `curve-002.json`, then re-run `node scripts/gen-curves.js` to update all five output curves.

### Fonts

`Train One` (headings) and `Montserrat` (body) loaded from Google Fonts in `index.html`. The neon glow aesthetic uses `text-shadow` with the brand palette: `#D65CFF` (purple), `#3F7CFF` (blue), `#64F4FF` (cyan), `#79FF5A` (green), `#FFF84A` (yellow).
